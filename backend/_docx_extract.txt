 NEPAL HEMOPHILIA DIGITAL MANAGEMENT SYSTEM Complete Project Report &amp; System Blueprint 1. Project Objective नेपालभरका Hemophilia patients, hospitals, Province Admin र Super Admin लाई एउटै secure digital system मा जोड्ने। Patient registration, verification, Unique Patient ID, treatment/injection records, hospital visits र nationwide reporting व्यवस्थापन गर्ने। 2. System Structure Public Website → Patient App → Central Database/API → Hospital Admins → 7 Province Admins → Super Admin → Reports 3. User Roles Super Admin: सम्पूर्ण Nepal को system, provinces, hospitals, patients, treatment/injection records, reports, notifications, settings र audit logs manage गर्ने। Province Admin: आफ्नो प्रदेशका patients, hospitals, Hospital Admins, verification र province-level reports manage गर्ने। Hospital Admin: Patient ID search गरेर registered patient को नयाँ injection/treatment record थप्ने र आफ्नो hospital का reports हेर्ने। Patient: आफ्नो profile, Unique Patient ID, treatment/injection history, hospital visits, notifications र permitted information हेर्ने। 4. Seven Province Administration Koshi Province Madhesh Province Bagmati Province Gandaki Province Lumbini Province Karnali Province Sudurpashchim Province 5. Patient Registration &amp; Verification Patient ले नाम, जन्ममिति, लिङ्ग, मोबाइल, प्रदेश, जिल्ला, स्थानीय तह, वडा, ठेगाना, blood group, hemophilia type/severity, hospital, emergency contact र आवश्यक documents भर्ने। Registration सम्बन्धित Province Admin मा जान्छ। Verification पछि Patient ID र login account उपलब्ध हुन्छ। 6. Unique Patient ID &amp; Cross-Hospital Treatment प्रत्येक patient लाई permanent Unique Patient ID दिइन्छ, उदाहरण: HEM-000123। Patient जुनसुकै registered hospital मा गए पनि Hospital Admin ले यही ID search गरेर patient verify गर्न र नयाँ injection/treatment record थप्न सक्छ। नयाँ record central database मा patient को history सँग link हुन्छ। एक hospital ले अर्को hospital ले बनाएको पुरानो treatment record edit/delete गर्न नपाउने; correction र audit trail राख्ने। 7. Patient App Features Login, Registration, Patient ID, Profile, Treatment History, Injection History, Hospital Visit History, Medical Records, Emergency Information, Notifications, Settings, Password Change, Help &amp; Support. 8. Hospital Admin Features Dashboard, Search Patient, View Patient Profile, Add Injection, Add Treatment, Patient History, Hospital Patients, Daily/Weekly/Monthly/Yearly Reports, PDF/Excel Export, Notifications, Profile and Settings. 9. Province Admin Features Dashboard, Patient Verification, Patient Management, Hospital Management, Hospital Admin Management, Treatment/Injection Monitoring, Province Reports, Notifications and Settings. 10. Super Admin Features National Dashboard, 7 Province Management, Province Admin Management, Hospital Management, Hospital Admin Management, Patient Management, Treatment Management, Injection Management, Reports, Audit Logs, Notifications and System Settings. 11. Website Home, About Hemophilia, About Nepal Hemophilia, Services, Hospitals/Care Centers, Province Information, Doctors/Health Professionals, News, Notices, Events, Resources, Gallery, Emergency Information, Contact and Patient Login. Private patient medical data public website मा देखाइने छैन। 12. Reports Patient Reports: total, province-wise, district-wise, hospital-wise, age group, gender, hemophilia type. Treatment Reports: daily, weekly, monthly, yearly, province-wise, hospital-wise, patient-wise. Injection Reports: factor-wise, dose-wise, hospital-wise, province-wise, date-wise. Hospital Reports: patient count, injections, treatments and activity. Export: PDF, Excel and Print. 13. Dashboard Key indicators: Total Patients, Total Hospitals, Total Injections, Total Treatments, Active Patients. Province-wise charts and filters राख्ने। 14. Security &amp; Privacy Role-based access control, secure authentication, strong password policy, audit logs, session management, backups र appropriate data protection लागू गर्ने। Patient को sensitive medical information permission बिना public वा unauthorized users लाई नदेखाउने। 15. Notifications Patient: registration approval, account creation, treatment added, important notices. Hospital/Province/Super Admin: verification requests, system alerts, activity and important notices. 16. Main Database Tables users, roles, provinces, districts, hospitals, hospital_admins, province_admins, patients, patient_documents, patient_verification, treatment_records, injection_records, hospital_visits, factors_medicines, notifications, reports, audit_logs, system_settings. 17. Recommended Technology Patient App: Flutter/Android. Admin Panel: Responsive Web Application. Website: Responsive Web. Backend: REST API. Database: PostgreSQL or MySQL. Reports: PDF + Excel. Hosting: Secure cloud/server. 18. Final Workflow Patient Registration → Province Selection → Province Admin Verification → Patient ID &amp; Account → Patient Login. Patient visits any registered hospital → Hospital Admin searches Unique Patient ID → verifies patient → adds injection/treatment → record is saved centrally → patient history updates → authorized Province/Super Admin can view reports. 19. Project Goal नेपालभर Hemophilia patient care, treatment tracking, hospital coordination, administration र reporting लाई एकीकृत, सुरक्षित र व्यवस्थित digital platform मा रूपान्तरण गर्नु।
